Overview

The third dataset I chose for Project 2 is Shanice’s data on U.S. cities that reported car thefts. The cities are currently stored as column groups, I will use pivot_longer() to reshape the dataset into a tidy format. The goal will be to have one row for each city and month, with columns for the number of Kia/Hyundai vehicles, the total number of vehicles, and the percentage. For the analysis, I could compare the percentage of Kia/Hyundai vehicles across cities and examine how the percentages change over months. I can also use a visualization to show differences between cities and changes over time.

Prepare the car theft dataset by renaming the month column, removing rows without a month, and assigning consistent temporary names to each city’s three columns.

# Rename month column and remove NAs
car_thefts <- df |>
  rename(month = 1) |>
  filter(!is.na(month))

# Get city names from the first column of each 3 column group
city_names <- names(car_thefts)[seq(2, ncol(car_thefts), by = 3)]

# Give each city's columns temporary names
names(car_thefts) <- c(
  "month",
  as.vector(sapply(seq_along(city_names), function(i) {
    c(
      paste0("city", i, "_kia_hyundai"),
      paste0("city", i, "_all"),
      paste0("city", i, "_percent")
    )
  }))
)

Transform the data from wide to long format so each row represents a city and month, separate city and state names, and rename the columns.

car_thefts_long <- car_thefts |>
  pivot_longer(
    cols = -month,
    names_to = c("city_id", ".value"),
    names_pattern = "^city(\\d+)_(kia_hyundai|all|percent)$"
  ) |>
  mutate(city = city_names[as.integer(city_id)]) |>
  tidyr::separate(
    city,
    into = c("city", "state"),
    sep = ",\\s*",
    fill = "right",
    extra = "merge"
  ) |>
  select(-city_id) |>
  rename(
    kia_hyundai_count = kia_hyundai,
    total_vehicle_count = all,
    theft_percentage = percent
  )

Calculate the average theft percentage for each city, ignoring missing values, and sort the results from highest to lowest. This makes it easier to identify and compare cities with the highest average Kia and Hyundai theft percentages.

city_summary <- car_thefts_long |>
  group_by(city) |>
  summarise(
    average_percentage = mean(theft_percentage, na.rm = TRUE),
    .groups = "drop"
  ) |>
  arrange(desc(average_percentage))

Select the ten cities with the highest valid average theft percentages. It excludes non-finite values like Na and NaN, and limits the results to exactly ten cities, even if there are ties.

top_10_cities <- city_summary |>
  filter(is.finite(average_percentage)) |>
  slice_max(
    order_by = average_percentage,
    n = 10,
    with_ties = FALSE
  )

Create a horizontal bar chart showing the ten cities with the highest average Kia/Hyundai theft percentages. Each bar is labeled with its percentage, and a color gradient helps distinguish values. The chart includes a title, axis labels, and extra space for the percentage labels so the results are easier to read.

ggplot(
  top_10_cities,
  aes(
    x = reorder(city, average_percentage),
    y = average_percentage,
    fill = average_percentage
  )
) +
  geom_col() +
  geom_text(
    aes(label = paste0(round(average_percentage, 1), "%")),
    hjust = -0.2
  ) +
  coord_flip() +
  scale_fill_gradient(
    low = "lightblue",
    high = "darkblue",
    guide = "none"
  ) +
  labs(
    title = "Top 10 Cities by Average Kia/Hyundai Theft Percentage",
    x = "City",
    y = "Average theft percentage (%)"
  ) +
  theme_minimal() +
  scale_y_continuous(
    expand = expansion(mult = c(0, 0.12))
  )

Conclusion

The dataset was transformed from wide to long format, with one row for each city and month and separate columns for Kia/Hyundai theft counts, total vehicle counts, and theft percentages. The analysis calculated the average theft percentage for each city and used a bar chart to compare the ten cities with the highest averages. The results showed differences across cities, with Milwaukee having the highest average percentage among the cities examined. Missing values were retained when their meaning could not be confirmed, rather than automatically replacing them with zeros.

For future analysis, the dataset could be used to examine how Kia/Hyundai theft percentages changed over time and whether cities experienced similar trends the same time range.
